# Map Check Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A localhost web page that turns a 2D Nav2 map into a sim arena teammates can tune and save, and renders Tinker at chosen poses on it with overlap flags.

**Architecture:** A self-contained uv project at `tools/map_check/` has two parts.
- **Backend:** FastAPI, holding all geometry, storage, the shared bench and the render job queue.
- **Frontend:** Vite + React + TypeScript, built to `web/dist` and served by FastAPI.

Isaac renders run as a separate subprocess under the repo's root `.venv` Isaac Python (`map_check/render/isaac_render.py`), started per job and fed a JSON job file. Pure geometry modules (FK, cameras, labels) import with only numpy, so both Pythons can use them.

**Tech Stack:**
- Python 3.12, a uv project with its own `tools/map_check/.venv`: fastapi, uvicorn, python-multipart, numpy, scipy, pyyaml, pillow, usd-core; pytest and httpx for tests.
- Node 24: React 18.3.1, TypeScript 5.6, Vite 5.4, vitest 2.1, three (+ @types/three). These are Map Studio's versions, plus three.
- Isaac Sim 6.0.1 via `/home/tinker/tinker-sim/6.0.1/.venv/bin/python`.

**Spec:** `docs/superpowers/specs/2026-10-17-map-check-design.md`, plus the mockups and prototypes in `docs/superpowers/specs/2026-10-17-map-check/`. Read the spec before any task.

## Global Constraints

- **Network:**
  - Bind `127.0.0.1` only, default port `9081`.
  - Refuse cross-origin browser requests with Map Studio's `origin_allowed` rule, copied into `map_check/server.py`: no Origin → allowed; otherwise the scheme must be http(s), the netloc must equal Host, and the hostname must be in `{localhost, 127.0.0.1, ::1}`.
- **Map Studio is never modified.**
  - Its `*.poses.yaml` files are read only.
  - The only writes into `<nav maps dir>` are *new* `<name>.yaml` + image files for uploaded maps.
- **Never overwrite:**
  - an existing map file;
  - an arena version directory.

  `current.json` is replaced atomically (write a temp file, then `os.replace`).
- **Name rules** (copied from Map Studio `names.py`):
  - map names `[A-Za-z0-9_][A-Za-z0-9_.-]{0,99}`, with no `..` and not ending in `.poses`;
  - pose names `[A-Za-z0-9_]{1,64}`.
- **Default paths (all configurable):**
  - nav maps dir: `/home/tinker/tk25_ws/src/tk26_navigation/src/navigation_bringup/maps`
  - arena root: `<repo>/artifacts/arena`
  - robot pointer: `<repo>/artifacts/robot/tinker2/current.json`
  - arm poses: `/home/tinker/tk25_ws/src/tk25_decision/src/behavior_tree/behavior_tree/HRI/constants.json`. Never the `HRI/HRI/` copy.
  - state: `<repo>/outputs/map_check/`
  - Isaac Python: `<repo>/.venv/bin/python`
- **Build defaults:**
  - wall height `0.60` m;
  - "fill closed outlines up to" `4.0` m²;
  - default shape height `0.60` m;
  - the occupancy rule is Nav2 trinary (occupied when `(255−v)/255 > occupied_thresh`, honoring `negate`).
- **Overlap:**
  - margin `0.02` m, stricter (a pose is flagged when its clearance is under 2 cm);
  - flag text reports the real distance, e.g. "arm (link3) overlaps wall by 3 cm" or "base 1 cm from shape 7 (under 2 cm)".
- **Head camera:**
  - 1280×720, 90° HFOV, mount `head_camera_color_optical_frame`, optical→USD rotation wxyz `(0, 1, 0, 0)`, from `simulation/sensors/hardware-parity.json`;
  - pan `pan_joint` limits ±180°, tilt `tilt_joint` −30°…+90°.
- **Renders:**
  - one Isaac process per job, exiting when the job is done;
  - at most 6 close-up render products per orchestrator step, with the overview in its own step;
  - hard timeout `min(1800, 120 + 20 × views)` s, killing the whole process group;
  - time estimate shown in the UI: `40 + 3 × views` s.
- **GPU busy:**
  - any nvidia-smi compute app on either GPU, or a running process whose cmdline contains `run_sim.py`, `gpsr-stack`, `isaac-sim` or `omni.kit`, and which isn't Map Check's own job;
  - when busy, don't start; the override is one explicit click per render;
  - when both GPUs are free, prefer GPU 1.
- **Shared tree:** commit only the files a task lists. Never `git add -A` or `git commit -a`. Other sessions have unrelated modified files in this repo.
- **UI:**
  - dark theme;
  - copy names things as the teammate sees them;
  - the IBM Plex Sans / IBM Plex Mono tokens from mockup `check-poses-v7.html`, which is the visual reference for both screens.

## Review Focus

1. **Bad names in uploads or the save field** (`../x`, `a b`, `.hidden`, `x.poses`): refuse with the rule shown, and write nothing. Tested in Task 4 and Task 12.
2. **Pasted Map Studio code in odd shapes:** CRLF line endings, no import lines, several blocks on one line, a non-normalized quaternion, one garbled block among good ones. Parse the good blocks, report the bad one by its position, and get yaw from `atan2`. Tested in Task 5.
3. **Map files that aren't the 5 cm PGM:** a PNG, an RGBA PNG, `negate: 1`, a relative `image:` path, a yaml whose image is missing from the upload. Either parse correctly or fail with a message naming the problem. Tested in Task 2.
4. **Two teammates press Render on the same map, or the server restarts mid-job:** the second job queues, and a restart marks the running job "interrupted" and leaves no Isaac process behind. Tested in Task 11.
5. **A pose outside the arena's footprint, or exactly on a wall cell:** the overlap check still answers. Outside reads "outside the arena", and a pose on a wall reads as an overlap rather than crashing. Tested in Task 7.

  - A pose whose base_link origin is outside `arena_bounds` (the union of the boxes' xy) → one `outside` flag, "outside the arena", and the rest are skipped.
  - At most one flag per part, the worst one, sorted by distance.
